# Ai Software Factory

Positioning: Autonomous software factory. Research to verified releases.

## Launch copy

I wanted a software factory that takes a useful idea through implementation, tests, documentation and a verified release.

The first shipped example is README Proof: a CLI, browser UI, MCP tools and RVF evidence, published on npm. The platform now has verified workspace registration, project requests, free limits and an operator queue.

Start free with one project and one run request every 24 hours. Public requests require authorization. A queued request is not a shipped product.

Next project briefs include local MCP services, benchmark explorers and Rust backed Python integrations. These are ideas, not released products.

## Promotion rules

Product Hunt remains unpublished and unscheduled. Use real captures of the factory landing page alongside clearly labeled README Proof example captures. Do not represent generated interfaces as working features.

Link every release claim to its repository, registry version and evidence. Avoid virality guarantees, invented customer counts, fabricated benchmarks or claims of unattended public execution.
